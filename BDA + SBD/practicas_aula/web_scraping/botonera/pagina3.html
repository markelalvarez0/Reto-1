Curso de Python

Descripción del curso

El curso de Python está diseñado para quienes desean aprender a programar desde cero o mejorar sus habilidades en uno de los lenguajes más demandados del mercado. Aprenderás sobre estructuras de datos, funciones, clases y mucho más.

Temario:

  • Introducción a Python
  • Estructuras de datos
  • Funciones y módulos
  • Orientación a objetos en Python
