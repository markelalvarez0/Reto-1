Curso de Odoo

Descripción del curso

El curso de Odoo está enfocado en aprender a manejar este ERP (Enterprise Resource Planning) que es una de las herramientas más poderosas para la gestión empresarial. Desde la instalación hasta la configuración de módulos específicos para cada área de negocio.

Temario:

  • Introducción a Odoo
  • Configuración del sistema
  • Módulos de ventas y contabilidad
  • Gestión de inventarios
