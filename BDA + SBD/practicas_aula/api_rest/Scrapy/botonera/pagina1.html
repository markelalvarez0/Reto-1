Curso de Big Data

Descripción del curso

El curso de Big Data te proporcionará los conocimientos fundamentales para el manejo de grandes volúmenes de datos. Aprenderás a gestionar bases de datos distribuidas, técnicas de análisis de datos masivos, y a usar herramientas como Hadoop y Spark.

Temario:

  • Introducción a Big Data
  • Herramientas de procesamiento masivo de datos
  • Fundamentos de Hadoop
  • Uso de Apache Spark
