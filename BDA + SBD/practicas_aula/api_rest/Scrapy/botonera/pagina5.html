Curso de MongoDB

Descripción del curso

El curso de MongoDB te enseñará cómo trabajar con bases de datos NoSQL. Aprenderás a crear, consultar y administrar bases de datos en MongoDB, además de realizar análisis de datos avanzados con esta potente herramienta.

Temario:

  • Introducción a MongoDB
  • Instalación y configuración
  • Consultas en MongoDB
  • Análisis de datos NoSQL
